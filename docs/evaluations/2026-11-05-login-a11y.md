# Evaluation — 2026-11-05 — accessibility of /login

**Target:** live URL (https://lakat-iloilo.vercel.app/login), logged out
· **Scope:** AGENTS.md 4.8 (accessibility, WCAG 2.2 AA) on `/login` only
· **Run with:** `/evaluate-app a11y /login`, in Brave with the Claude
extension

## Verdict

Keyboard use, labels and error messages are solid; the small text on the
glass card was too faint (B6, fixed below). The field focus border (B3
from 2026-11-04) passes, just.

## Findings

### A. Spec

None.

### B. Accessibility

- **[Medium] B6 — Small text on the login card was too faint
  (WCAG 1.4.3, needs 4.5:1).** Measured from screen pixels (±0.2):
  placeholders 2.2:1, "Just looking? Explore as a guest" 2.8:1, field
  labels 3.2:1, "Show" 3.7:1, error messages 3.9:1. Large heading passes.
  - Cause: the card is light glass (`bg-white/15`, `AuthShell.tsx`) and
    each field adds `bg-white/10` (`GlassField.tsx`), over a mid-green
    photo. The background got so light that even pure white text inside
    a field reached only 4.1:1.
  - Also on Forgot password and Set new password (same card).
  - **Fixed 2026-11-05 — see below.**
- **[Medium] B7 — Fields don't say what they are for autofill
  (WCAG 1.3.5).** Email `autoComplete="off"`, password `"new-password"`
  in log-in mode (`LoginForm.tsx`).
  - **Team decision (2026-11-05): keep as it is.** The team does not want
    the browser to fill in saved emails or passwords on Log in or Create
    account. Recorded here so later evaluations do not re-raise it.
- **[Low] B3 — Field focus border passes, barely.** Focused border
  3.0:1 against the card (minimum 3:1); the change from unfocused is only
  1.8:1. Optional: `focus-within:ring-2 focus-within:ring-white` in
  `GlassField.tsx`. The team found the Email field by pressing Tab.
- **[Low] B8 — Two buttons are both called "Log in"** (the mode switch
  and the submit button). Optional: name the switch differently or use
  `role="tablist"`.

## What was checked, how, and what was NOT checked

- Checked in the browser with JavaScript (names, labels, ARIA, Tab order
  via focus events, sizes), zoomed screenshots (focus rings), pixel
  sampling of a saved screenshot with Python (contrast), an empty submit
  (page's own checks only — no backend call in the network log), a
  320/375 px frame (reflow), and axe-core run once in the console.
- **Not checked:** Create account mode; the Forgot / Set password pages
  themselves; a real screen reader; real log-in answers (nothing real
  was submitted); "reduce motion" on a device (code only); browser zoom
  itself (Brave did not resize; the 320 px frame covers reflow).

## Team results (2026-11-05)

- After a hard refresh of `/login`, the team could see the placeholder
  "you@example.com" and "Just looking?" — before the B6 fix, on a
  laptop.
- Pressing Tab reached the Email field (B3).

## Fixes after the evaluation

**2026-11-05, team request: B6 fixed (not yet committed).**

- `src/components/AuthShell.tsx` — the card is dark glass
  (`bg-teal-950/40`) instead of light glass (`bg-white/15`). This card is
  shared by Log in, Forgot password and Set new password.
- `src/components/GlassField.tsx` — the field's own tint is `bg-white/5`
  (was `/10`) and placeholders are `white/70` (was `/50`).
- **Checked:** `npx tsc --noEmit`, eslint on both files and
  `npm run build` pass. On the team's dev server (`localhost:3000/login`,
  1920 px wide), pixels sampled from a saved screenshot after an empty
  submit:

  | Text | Before | After |
  |---|---|---|
  | Placeholder | 2.2:1 | 4.7:1 ✅ |
  | Field label | 3.2:1 | 5.6:1 ✅ |
  | "Show" | 3.7:1 | 6.6:1 ✅ |
  | Error message | 3.9:1 | 7.1:1 ✅ |
  | "Just looking?" | 2.8:1 | 6.6:1 ✅ |
  | Focused field border (B3) | 3.0:1 | 4.6:1 ✅ |

- **Faint field outline — fixed 2026-11-05 (team request, not yet
  committed):** `GlassField.tsx` border `white/45` (was `/25`), selected
  `white/90` (was `/60`). Calculated on the dark card: unfocused 2.0 → 3.3:1,
  focused 4.6 → 8.1:1, difference between the two 2.5:1. Lint, tsc and
  build pass. **Team confirmed on localhost (2026-11-05):** the outlines
  are visible before clicking and brighter when a field is selected.
- **B8 — parked** in `docs/LATER.md` (team decision, 2026-11-05).
- **Team confirmed on localhost (2026-11-05):** the `/login` card is
  darker and the placeholder and "Just looking?" are easy to read; in
  Create account, an empty submit shows the yellow messages, readable;
  `/forgot-password` has the same darker card.
- **Pushed (commit f11013d) and deployed:** the live HTML of
  `/forgot-password` and `/reset-password` carries the new
  `bg-teal-950/40` card (checked with curl, 2026-11-05). `/login` draws
  its card in the browser, so it is not in the HTML.
- **Team confirmed on the live URL (2026-11-05):** `/login` has the
  darker card and the app runs smoothly.
- **Team confirmed (2026-11-05):** the reset email arrives at the
  team's own verified address, and its link opens `/reset-password`
  (Set new password).
- **Team confirmed (2026-11-05):** the Set new password card is darker
  and easy to read. **B6 is done on every page that uses the card** (Log
  in, Create account, Forgot password, Set new password; live URL for
  Log in).
